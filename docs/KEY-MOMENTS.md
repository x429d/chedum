# Критические позиции и ключевые моменты

## Два разных понятия

- **Критическая позиция** (`move_evaluations.is_critical`) — любой ход, где
  разрыв между лучшей и второй линией MultiPV ≥ 10 Win%. Это свойство
  позиции, а не ошибка игрока; оно нужно графику и подсказкам.
- **Ключевой момент** (`move_evaluations.is_key_moment`) — отобранная ошибка
  **игрока** для отчёта, графика и Retry. Не больше 8 на партию.

## Алгоритм отбора

Файл `src-tauri/src/analytics/moments.rs`, именованные константы:

| Константа | Значение | Смысл |
|---|---|---|
| `KEY_MOMENT_MAX` | 8 | максимум моментов на партию |
| `KEY_MOMENT_MIN_LOSS` | 8.0 | минимальная потеря Win% |
| `KEY_MOMENT_MIN_GAP` | 3 | минимум полуходов между моментами |
| `KEY_MOMENT_EQUAL_WIN` | 50.0 | «было не хуже» по Win% |
| `KEY_MOMENT_EQUAL_BONUS` | 10.0 | приоритет равных/выигрышных позиций |

1. Кандидаты — только ходы игрока (цвет берётся из `user_color`; для старых
   записей сторона восстанавливается по `fen_before`).
2. Категория — неточность, ошибка, зевок или упущенный шанс, потеря Win%
   не меньше 8. Порог важнее ярлыка: крупная «неточность» тоже попадает.
3. Приоритет = потеря Win%, +10, если до хода было равенство или лучше.
4. Жадный отбор по приоритету; кандидат ближе 3 полуходов к уже выбранному
   пропускается; максимум 8.
5. Результат сортируется по полуходу и сохраняется в `is_key_moment`;
   `game_analyses.key_moments_count` равен числу выбранных.

Retry использует ровно этот набор (`isKeyMoment`) и не показывает ходы
соперника.

|---|---|
| медиана | 3 |
| среднее | 3.44 |

Партия Wakanov–KKolobe (id 843): 7 моментов вместо прежних 26.

## Пересчёт

`backfill_key_moments` пересобирает флаги из сохранённых оценок (движок не
нужен), обновляет `key_moments_count` и текст резюме. Версия —
`key_moments_version`; повторный запуск идемпотентен.

# Performance Elo и Performance Rating

## Что показывается теперь

- **В отчёте одной партии** — `Performance Rating` по результату: рейтинг
  соперника +400 за победу, 0 за ничью, −400 за поражение. Это классическая
  оценка одной партии; она не зависит от точности и не притворяется измерением
  силы игры.
- **В хабе** — средняя оценка `Performance Elo` по точности **только при
  n ≥ 20 разобранных партиях**, с разбросом (± стандартное отклонение) и
  подписью «оценка по точности, экспериментально».
- При n < 20 карточка показывает «—» и подсказку, сколько партий нужно.

## Почему оценка по точности убрана с уровня партии

Замер на локальной базе (154 анализа, глубина 14/18/22, ник `Wakanov`,
рейтинги 880–1030):

| Связь | Pearson | Spearman |
|---|---|---|
| реальный Elo ↔ точность | 0.283 | 0.256 |
| реальный Elo ↔ ACPL | −0.129 | −0.130 |
| реальный Elo ↔ прежний Performance Elo | 0.363 | — |

Прежняя формула (`base_elo + (accuracy − 75)·18 − (acpl − 35)·4.5`) на этих
данных давала средний сдвиг **−109.6 Elo** и среднюю абсолютную ошибку
**283.6 Elo**. Пример из задания — «513 при рейтинге 1021» — следствие этой
формулы: при точности около 40 % и большом ACPL она уходит далеко вниз.

Доля объяснённой дисперсии r² ≈ 0.08. Этого недостаточно, чтобы показывать
число как рейтинг конкретной партии. Поэтому:

1. на уровне партии остаётся только результат-based Performance Rating;
2. в хабе оценка по точности сохраняется как экспериментальная, с n и
   разбросом;
3. формула и ограничения зафиксированы здесь.

## Формула хаба

`performance_elo(базовый рейтинг игрока, точность, ACPL) =
clamp(base + (accuracy − 75)·18 − (ACPL − 35)·4.5, 400, 3200)`.

Среднее и стандартное отклонение считаются по значениям `white_perf_elo` /
`black_perf_elo` разобранных партий. Значение обновляется при каждом чтении
хаба; при добавлении анализа другой конфигурации агрегат будет ограничен
одной конфигурацией (см. T13.6).

## Что это не означает

- Это не рейтинг Chess.com/FIDE и не предсказание результата.
- Точность и ACPL зависят от глубины движка: значения разных глубин
  несравнимы и не должны смешиваться.
- При малой выборке (n < 20) любая оценка силы по точности не показывается.
